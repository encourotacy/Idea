# 学生 C 技术方法与学习补充

配套文档：[学生C工作说明.md](./学生C工作说明.md)

这份文档回答两件事：四项任务实际要用哪些技术方法，以及为了把这些方法做出来，需要先学会什么。范围只覆盖学生 C 的数据、信号和耦合剂控制，不展开学生 A 的结构和学生 B 的运动控制软件。

信号链以相控阵超声为主。规范同时要求评估速度对涡流幅值的影响，并把涡流数据纳入同步追溯，所以涡流只学到能读懂幅值、提离和干扰，不把涡流探头设计当成主线。

## 先补的公共基础

后面四项都建立在同一套检测和数据概念上。T0+30 天写需求规格之前，这些要能自己讲清楚。

| 要会的内容 | 用在哪里 | 学到什么程度 |
| --- | --- | --- |
| 纵波、横波、声速、波长、折射 | 看懂楔块角度和声程 | 能用斯涅尔定律说明斜入射后波型如何转换 |
| 耦合 | C-1 的幅值变化、C-4 的供水 | 知道水膜过薄会掉波，过厚会带来水层噪声 |
| A 扫、B 扫、C 扫、S 扫 | 所有超声数据 | 能指出闸门内峰值、声程、扫查位置各在哪一轴 |
| 相控阵延时、聚焦、线扫与扇扫 | C-2 的双线阵数据 | 知道一次激发得到的是一条声束，不是一张照片 |
| 编码器位置 | 与 B 的同步接口 | 知道周向位置来自编码器计数，不是来自墙钟时间 |
| 信噪比、幅值均值与波动 | C-1、C-4 的评价指标 | 能用同一套指标比较不同速度、不同流量下的信号 |

探头型号按供货明细读：`5DL32-1.5×16` 是 5 MHz 双线阵，阵元间距 1.5 mm，阵元高度 16 mm。型号里的 32 是阵元规模，两片阵各有多少阵元以探头说明书为准。频率决定后续带通滤波的中心频率，不要套用别的探头参数。

建议材料：相控阵检测教材里「声束形成、扫查显示、校准试块」三章；仪器厂商的 A/B/S 扫说明。先在试块或仿真数据上把闸门、声程、编码器三列对齐，再进入算法。

## C-1 信号处理与干扰抑制

对应规范 5.1.1(6)、5.1.1(22)。目标是定量说明扫查速度如何改变超声和涡流幅值，并把电机杂散电流造成的干扰压到可接受水平。

### 要用的方法

1. **控变量实验。** 在同一试块、同一闸门、同一耦合条件下，只改变扫查速度（覆盖爬行器 1～120 mm/s 里的低速段和高速段）。每个速度重复多次，记录闸门内峰值、声程和编码器位置。
2. **速度–幅值定量关系。** 用相关系数和回归描述幅值随速度的变化，同时给出均值、标准差和变异系数。低速段波动目标约 ±2%，高速段约 ±5%，实验曲线要能和 B 的速度记录对上。速度主要改变的是空间采样密度和耦合水膜稳定性：同样的脉冲重复频率下，走得越快，单位长度上的采样点越少。
3. **频谱分析。** 对 A 扫和编码器速度做傅里叶变换，把探头中心频率附近的有用频带和电机驱动带来的杂散谱线分开。杂散电流干扰通常表现为固定频率的尖峰或宽带底噪抬升，而不是缺陷回波那种随位置出现的局部峰值。
4. **滤波与降噪。** 在探头中心频率附近做带通；对沿扫查方向的慢变漂移用滑动平均或中值；对突发毛刺用中值或小波。滤波前后用同一闸门比较信噪比和缺陷峰值，避免把缺陷波滤掉。
5. **信号质量评估。** 固定一套指标：信噪比、闸门峰值变异系数、有效采样密度（点/mm）、干扰谱线相对主频的衰减量。后续 C-4 的耦合实验沿用这套指标，这样不同报告可以比较。

### 需要学习的内容

- 采样、脉冲重复频率和扫查速度的关系，能估算给定速度下每毫米有多少个 A 扫
- 傅里叶变换和功率谱，能从图上指出信号频带和干扰频带
- 带通、滑动平均、中值、小波各自适合什么噪声
- 相关、回归和重复实验的基本统计，能写清样本量和波动范围
- 涡流幅值、提离和速度的基本关系，能把涡流幅值用同一套统计量报出来
- 电机 PWM、接地和共模干扰的概念，能和 B 讨论屏蔽、接地和采集触发，而不改运动控制本身

## C-2 多通道融合与缺陷识别

对应附录 2。`5DL32-1.5×16` 一次扫查要完成两个方向的横向缺陷检测。C 不设计探头，负责两路数据对齐之后的融合、识别和定位。

### 要用的方法

1. **双向采集对齐。** 两片线阵各看一个相反方向。每一帧同时记下通道号、声束角度、声程、幅值和编码器位置。融合之前先把两路数据变到同一条扫查坐标上。
2. **位置配准。** 以编码器计数为主键，把两路指示对齐到同一周向位置。存在固定安装偏移时，用试块上的已知反射体标定一个位置零点差，以后按这个差值平移。
3. **多通道融合。** 同一位置、同一深度附近，两路都超过阈值才保留，用来压低单路偶发噪声；只在一路稳定出现的指示单独标记，避免漏掉方向性强的横向缺陷。融合结果保留原始两路幅值，不只留一个合并数。
4. **缺陷识别。** 在闸门内做幅值阈值，再沿扫查方向把连续超阈点收成一个指示。报告每个指示的起点、终点、最大幅值位置和对应声程。
5. **定位。** 周向位置来自编码器；深度方向用声程和楔块折射角换算。定位误差要和重复安装精度、编码器分辨率分开写，不把机械误差算进算法误差。
6. **验证。** 在带已知反射体的试块上做：该报出的位置是否报出，空段是否保持安静。统计检出数、漏报数和误报数。探头未到货时，用仿真 A 扫或公开的相控阵试块数据把这条流程先跑通。

### 需要学习的内容

- 双线阵一次双向扫查的几何：两路声束方向、楔块角度、横向缺陷的走向
- 闸门、声程、跨距和深度换算
- 阈值、连通区域和沿扫查轴聚类
- 用已知反射体做检出和误报统计的实验设计
- 相控阵数据文件里通道、声束、编码器通常如何排列，能写成自己的读取程序

## C-3 数据管理与图像处理

对应 5.1.1(15) 的信息记录和 5.1.1(14) 的摄像头录像。摄像头选型和安装归学生 A，C 负责记录格式、图像处理和多源对齐。

### 要用的方法

1. **统一主键。** 每条记录至少包含：采集时钟、编码器位置、扫查速度、通道、幅值、声程，以及对应的图像帧号。超声、涡流、位移、图像都挂在「位置 + 时间」上，避免各存各的文件夹对不上。
2. **同步。** 优先用编码器脉冲或 B 给出的触发对齐采集；只有软件时间戳时，要估计各设备时钟差并写进记录。同步误差单独测量，不和缺陷定位误差混在一起。
3. **图像处理。** 1080P 画面用于辅助对准焊缝，不做缺陷判伤。可用边缘或直线检测找出焊缝中心线，把中心偏移量随编码器位置存下来。镜头上有水雾时先做对比度拉伸和感兴趣区域裁剪，再做直线检测。
4. **追溯。** 任意一个缺陷指示都能回放到原始 A 扫、当时速度、耦合状态和最近的视频帧。信息记录模块的字段和 B 的软件一起定，C 提供字段表和示例文件。

### 需要学习的内容

- 时间戳、硬件触发和编码器同步的差别
- 一种表格或层次数据格式（如 CSV 加索引，或 HDF5），能按位置查询
- OpenCV 里的裁剪、对比度、边缘和直线检测
- 与 B 的接口字段：运动状态、触发、帧号、文件路径

## C-4 耦合剂供给控制

对应 5.1.3。规范指标是压力与流量可调，气囊充压最大 1.0 MPa，罐体 1 升，12 V 锂电池。设计方案 1.5 节目前写的是隔膜泵、手动调节阀和 PU 水管。控制方法按「流量跟着扫查速度走」来写；执行机构以最终冻结的供水结构为准。

### 要用的方法

1. **流量–速度匹配。** 单位时间供水量要跟着扫查速度变化：走得快，单位时间需要的耦合介质量更大，才能维持相近的水膜。先在台架上测出「速度 → 目标流量」表，再交给 B 做成设定值。
2. **压力–流量特性。** 在固定管路下测压力和流量的关系，标出稳定耦合区间。压力过高会冲击楔块和表面，过低则耦合中断、幅值下跌。1.0 MPa 是规范给出的充压上限，实验在上限以内取工作点。
3. **和信号质量闭环。** 用 C-1 的同一套幅值指标，做速度×流量的搭配实验，找出幅值稳定、水层噪声可接受的区域。报告写匹配关系，以及离开这个区域时幅值如何变差。
4. **控制接口。** 向 B 提供设定流量或设定压力、实测流量、实测压力、故障（缺液、超压、断流）。若最终仍是手动阀，C 给出阀开度和速度的对照表；若是可调泵或阀，再给出调节规律。调节规律从实测特性来，不先假设复杂控制器。

### 需要学习的内容

- 流量、压力、管阻的基本关系，能读泵的压力–流量曲线
- 压力传感器和流量传感器的量程、输出信号
- 设定值、实测值和报警这三类接口数据
- 双因素实验：速度和流量一起变时如何列表、如何画幅值曲面

## 编程与工具

算法和实验处理用 Python 即可：NumPy 做数组和滤波，SciPy 做频谱和统计，Matplotlib 画速度–幅值曲线和频谱，OpenCV 做焊缝图像。数据量上来之后用 Pandas 或 HDF5 按编码器位置检索。

和 B 的接口先写成一份字段表和一组示例数据，再谈进控制软件。和 A 的接口主要是相机安装位置、画面里焊缝的朝向，以及振动会不会让直线检测失效。

探头未到之前，用仿真或等效试块数据把读取、滤波、对齐、出报告这条链跑通。仪器到货后只替换数据源，不重写流程。
