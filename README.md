# 自动检测机器人大创项目

本仓库供「创飞所有人」小组管理项目代码。仓库包含 `software` 和 `signal` 两个分支，分别由学生 B 和学生 C 负责。

## 使用方法

**▸ 克隆仓库**

在 VS Code 中配置好 Git 后，于终端执行：

```bash
git clone https://github.com/encourotacy/Idea.git
```

**▸ 切换到 `software` 分支**

克隆后默认处于仓库的默认分支。如需切换，进入仓库目录后执行：

```bash
cd Idea
git checkout software
```

**▸ 切换到 `signal` 分支**

```bash
cd Idea
git checkout signal
```
> [!warning] Tips
> *在 VS Code 左下角点击当前分支名，也可以直接切换分支，不必输入上面的命令。*

**※ 此仓库的默认分支为 `software`。**
